# A Mano Cuba — Android

Aplicación Android nativa en Kotlin + Jetpack Compose. El proyecto fuente completo está en `AmanoCubaAndroid_source.zip`.

## Descargar APK instalable
Abre la sección **Releases** de este repositorio y descarga `app-debug.apk`. El flujo de GitHub Actions compila una APK de depuración firmada para pruebas en Android cuando recibe el proyecto.

La primera compilación se ejecuta al subir este repositorio. Si el flujo termina correctamente, aparecerá una versión descargable en Releases.

## Funciones del proyecto
- Catálogo de alimentos con precios ingresados para cada mercado.
- Comparación de los últimos reportes locales por producto y mercado.
- Lista de compra, horario semanal y tareas de estudio.
- Temporizador de concentración y vista con texto más grande.
- Funcionamiento local sin conexión.

## Importante
Los precios y mercados se guardan en el teléfono donde se registran; esta versión no los sincroniza entre personas. La APK de depuración es instalable para probar, pero no es una versión publicada en Google Play.
